## Welcome to the PHMC Form Generator Source Code! 

My name is Frosty, I am the primary developer of this cool little project for a GTA World (EU) faction. This source code contains the majority of the code base (excluding .env) data. 

Coded in Javascript in Visual Studio Code, debugging assistance with Google Gemini 2.5.

Majority of the code is nested within the `app.js` file, with some important components branched off into the `/components` directory.  I'll continue to clean things up one day. 

All the important data `Form.Select`, dropdowns and other data is stored inside the `data.js` file, it's self explainatory. 

I'll eventually migrate this to a new version, such as Vite as Create-React-App is now depricated.
