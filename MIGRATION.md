# Migration Guide: From Create React App (CRA) to Vite

This guide provides instructions for migrating the PHMC Forms application from Create React App (CRA) to Vite. This migration improves build performance, development experience, and deployment flexibility.

## Prerequisites

- Node.js version 18 or higher
- npm or yarn package manager
- GitHub repository access for deployment

## Migration Steps

### 1. Update Package.json

Remove CRA-specific dependencies and scripts, then add Vite dependencies:

```json
{
  "dependencies": {
    // ... existing dependencies
  },
  "devDependencies": {
    "@vitejs/plugin-react": "^4.0.0",
    "vite": "^4.0.0"
    // Remove: react-scripts, cra-specific plugins
  },
  "scripts": {
    "start": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "deploy": "npm run build && gh-pages -d build"
    // Remove: start, build, test, eject from CRA
  }
}
```

Install the new dependencies:
```bash
npm install @vitejs/plugin-react vite --save-dev
```

### 2. Create Vite Configuration

Create `vite.config.js` in the project root:

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  base: '/forms/', // Required for GitHub Pages deployment
  build: {
    outDir: 'build' // Keep output directory as 'build' for consistency
  }
})
```

### 3. Move Index.html

Move `public/index.html` to the project root and update its content:

- Move the file from `public/index.html` to `./index.html`
- Update the script tag to reference the new Vite entry point:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <link rel="icon" href="/favicon.ico" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <meta name="theme-color" content="#000000" />
    <meta name="description" content="PHMC Forms Application" />
    <link rel="apple-touch-icon" href="/logo192.png" />
    <link rel="manifest" href="/manifest.json" />
    <title>PHMC Forms</title>
  </head>
  <body>
    <noscript>You need to enable JavaScript to run this app.</noscript>
    <div id="root"></div>
    <script type="module" src="/src/index.js"></script>
  </body>
</html>
```

### 4. Update Environment Variables (.env File)

Vite uses a different prefix for environment variables. Update your `.env` file:

**Before (CRA):**
```
REACT_APP_FIREBASE_API_KEY=your_api_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_auth_domain
REACT_APP_FIREBASE_PROJECT_ID=your_project_id
```

**After (Vite):**
```
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
```

Update your Firebase configuration in `src/firebase.js`:

```javascript
const firebaseConfig = {
  apiKey: import.meta.env.VITE_FIREBASE_API_KEY,
  authDomain: import.meta.env.VITE_FIREBASE_AUTH_DOMAIN,
  projectId: import.meta.env.VITE_FIREBASE_PROJECT_ID,
  // ... other config
};
```

### 5. Update Import Statements

Replace CRA-specific imports with Vite equivalents:

- Remove any `import 'index.css'` from `src/index.js` if it was auto-generated by CRA
- Ensure all asset imports use relative paths or public folder references

### 6. Update Build and Deployment Configuration

#### GitHub Pages Deployment

1. Create a `.nojekyll` file in the project root to bypass Jekyll processing:
   ```bash
   echo "" > .nojekyll
   ```

2. Ensure your `package.json` has the deploy script as shown above.

3. For GitHub Pages deployment, the `base: '/forms/'` in `vite.config.js` ensures assets are served correctly.

#### Manual Deployment

If deploying manually:

1. Run `npm run build`
2. Upload the `build/` directory contents to your hosting provider
3. Ensure the server serves `index.html` for all routes (SPA routing)

### 7. Testing the Migration

1. Start the development server:
   ```bash
   npm start
   ```

2. Verify all features work:
   - Firebase authentication
   - Form submissions
   - Modal components
   - Asset loading

3. Build for production:
   ```bash
   npm run build
   ```

4. Test the build locally:
   ```bash
   npm run preview
   ```

### 8. Common Issues and Solutions

#### Assets Not Loading
- Ensure `base: '/forms/'` is set in `vite.config.js` for GitHub Pages
- Verify `.nojekyll` file exists in the repository root

#### Environment Variables Not Working
- Confirm all env vars start with `VITE_`
- Restart the development server after changing `.env`

#### Build Errors
- Clear node_modules and reinstall: `rm -rf node_modules && npm install`
- Check for any remaining CRA-specific code

### 9. Rollback Plan

If issues arise:
1. Revert `package.json` to previous version
2. Restore `public/index.html`
3. Remove `vite.config.js`
4. Reinstall CRA dependencies

### 10. Performance Improvements

Vite provides:
- Faster cold start times
- Instant hot module replacement
- Optimized production builds
- Better tree-shaking
